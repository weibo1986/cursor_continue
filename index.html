快速开始

三步，即刻上手。

从安装到持续协作，只需几分钟。

1

安装插件

打开 Cursor，Ctrl+Shift+P 输入 Extensions: Install from VSIX...，选择 cursor-continue-x.x.x.vsix，等待自动重载。

2

激活卡密

底部出现 Cursor Continue 面板，输入卡密（CCG-XXXX-XXXX-XXXX-XXXX），点击「激活」，看到「已激活」即完成。

3

开始协作

点击「同步配置」→ 聊天框输入第一条消息 → 点击右下角 CC 按钮（橙色）发送。之后在底部面板输入框中输入指令，按 Enter 发送，循环往复，持续对话。

支持

常见问题。

面板一直显示"正在检查授权状态"？
确认已输入卡密并点击激活。如果持续卡住，尝试 Ctrl+Shift+P → Developer: Reload Window。
提示"授权已过期"？
卡密已过期，需要获取新的卡密重新激活。
Cursor 没有调用桥接脚本？
先点击「同步配置」确保工作区文件已部署，然后重新开始一个新的 Chat/Agent 会话。
换了电脑还能用吗？
每个卡密绑定一台设备，换电脑需使用新卡密。
