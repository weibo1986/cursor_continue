简介

让 Cursor AI 持续工作的协作扩展。

通过底部面板与 Cursor 保持不间断对话，无需反复手动发送消息。Cursor 完成一个任务后会自动等待你的下一条指令，让协作循环不中断，把你从重复操作中解放出来。

环境要求

开始之前，请确认你的环境满足以下条件。

Cursor Pro 账号

需登录具备 Pro 权限的 Cursor 账号，以保证 AI 功能正常使用。

网络代理

使用过程中需保持稳定的网络代理连接，插件会定期验证授权。

操作系统

支持主流桌面操作系统，任选其一即可。

Windows macOS Linux

账号设置

开启账号超额，保证额度用尽后 AI 仍可继续工作。

在 Cursor 账号设置中开启「超额（Usage-based / 超额用量）」，这样当订阅额度用尽后，AI 请求仍能继续使用，避免持续协作中途中断。

切换账号

当一个账号额度用尽，或需要在多个 Pro 账号之间轮换使用时，可按以下步骤切换登录账号：

  1. 打开 Cursor，点击右上角的设置图标（齿轮）进入设置面板。
  2. 在顶部找到账号区域，点击当前账号后选择「退出登录（Sign Out）」。
  3. 退出后回到登录页，使用新账号重新登录（Sign In）。
  4. 登录完成后，确认新账号已开启「超额用量」（参见上方说明）。
  5. 重新发起对话即可继续使用。
提示：仅在 Cursor 内退出 / 重新登录账号，不会影响插件卡密授权与已同步的工作区配置，换号后可直接继续协作。若切换后模型无法连接，请检查代理是否开启（参见关于代理设置）。
重要：若你使用「切号软件」切换账号，这类工具通常会重置机器码。由于卡密为设备绑定（绑定机器码），机器码被重置后原有授权会失效，此时需要重新激活卡密（参见激活卡密）。

IDE 设置

将网络模式改为 HTTP/1.1，提升连接稳定性。

打开 Cursor 设置，找到 Network 相关选项，将其改为 HTTP/1（HTTP1.1）模式，以保证插件与服务端的通信更稳定。

关于代理设置

模型无法使用，多为地区限制导致，需正确配置代理。

情况一：模型不可用（地区限制）

当出现下方报错时，说明该模型不对你当前所在地区提供服务：

Model not available
This model provider doesn't serve your region.

原因：Cursor 对中国大陆地区限制使用，大陆网络直连会被拒绝。

解决方法：
  1. 开启代理的「全局模式」，并启用「TUN 模式」。
  2. 在 Cursor 设置中将 Network 模式设为 HTTP/1.1。
  3. 完成后重启 Cursor 并重新连接。

情况二：代理为「规则模式」

如果你的代理使用的是规则模式（而非全局模式），需要在 IDE 中手动配置代理（proxy）才能正常连接。

解决方法：
  1. 在 Cursor 设置中找到 Proxy（代理）选项，填入本地代理地址，例如 http://127.0.0.1:7890。
  2. 代理端口需根据你自己代理软件的实际端口填写，请勿照抄示例端口。
  3. 保存后重启 Cursor 并重新连接。

安装插件

通过 VSIX 文件将插件安装到 Cursor。

下载插件（VSIX） 下载后按下方步骤安装
  1. 打开 Cursor。
  2. 按 Ctrl+Shift+P，输入 Extensions: Install from VSIX...。
  3. 选择刚下载的 cursorContinue.vsix 文件。
  4. 等待安装完成，Cursor 会自动重载；若没有自动重启，请手动重启 Cursor。
安装完成后，按 Ctrl+Shift+` 新建终端，在终端区域底部查看是否出现 Cursor Continue 面板，即表示插件安装成功。

激活卡密

使用卡密激活插件，开启协作功能。

  1. 安装完成后，按 Ctrl+Shift+`（或在菜单中点击「终端 → 新建终端」）新建一个终端。
  2. 底部会出现 Cursor Continue 面板。
  3. 输入你的卡密（格式：CCG-XXXX-XXXX-XXXX-XXXX）。
  4. 点击「激活」。
  5. 看到「已激活」后，重启 Cursor 客户端使激活完全生效。
激活完成后，Cursor 的提问框中会出现橙色的 CC 图标，代表插件已准备就绪、可以正常使用。

  1. 点击面板中的「同步配置」，使用默认配置即可，等待部署完成。
  2. 点击「检测状态」，即可查看当前运行状态。
  3. 状态正常如下图所示，即表示配置成功、可以开始使用。

发送第一条消息

用橙色 CC 图标发送第一条消息，建立与 Cursor 的会话连接。

  1. 在 Cursor IDE 的提问框中输入第一条消息，例如「你好」。
  2. 点击提问框右下角的橙色 CC 图标，发送消息并连接会话。
  3. 插件会自动尝试连接会话，期间可能反复重试连接，属于正常现象，请耐心等待连接完成。
  4. 连接成功后如下图所示，即可开始持续对话。
第一条消息必须用橙色 CC 图标发送，它负责建立会话连接；之后的消息只需在底部面板输入框中输入即可。

关于模型选择

  • 连接会话前请先选择好模型。
  • 连接成功后再切换模型无实际用途，会话仍使用初始连接时的模型。
  • 若最高级模型一直无法连接成功，可以尝试切换到其他模型再试。

持续对话

连接成功后，在插件面板中持续对话，无需手动操作。

连接成功后，就可以在插件底部面板的对话框中输入会话内容，按 Enter 发送。Cursor 完成当前任务后会自动等待你的下一条指令，如此循环往复，持续对话无需反复手动发送消息。

使用技巧

一些提升使用体验的小技巧。

  • 连接会话时可能需要多次重试，属于正常现象，请耐心等待。
